## What this is

Frontend logic for the static SPA. Each ES module loaded by `index.html`:

- `calculator.js` — core economics engine: cost/ROI/profit math from user inputs
  (charge per minute, utilization, threads, LLM size, hardware costs).
- `roi-calculator.js` — ROI/profit-over-time projections and break-even logic.
- `heatmap.js` — profitability heatmaps across parameter pairs
  (price×utilization, threads×price, threads×utilization).
- `charts.js` + `chart-manager.js` + `chart-plugins.js` — canvas chart rendering
  (price frontier, cost breakdown, profit over time, GPU comparisons); manager
  coordinates chart lifecycle, plugins add annotations/highlights.
- `main.js` — UI wiring/initialization; `debug.js` — developer diagnostics.
- `precalculated/results.js` — values generated by `run.py`, consumed so charts
  render without recomputation.
