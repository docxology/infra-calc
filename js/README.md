# js/

Frontend logic for the static SPA: `calculator.js` (core economics math),
`roi-calculator.js` (ROI/break-even projections), `heatmap.js` (profitability
heatmaps), `charts.js`/`chart-manager.js`/`chart-plugins.js` (chart rendering and
annotation), `main.js` (UI wiring), `debug.js` (diagnostics). `precalculated/`
holds `results.js` generated by `run.py`.

Contents: precalculated/, calculator.js, chart-manager.js, chart-plugins.js, charts.js, debug.js, heatmap.js, main.js, roi-calculator.js
