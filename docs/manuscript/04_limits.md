# Interpretation and limits

The scenario uses editable hardware, electricity and service assumptions.
It describes the software's estimates for those inputs. It treats billed
minutes as the revenue unit and applies the energy price only during the
configured hours. The memory model uses available VRAM and a per-instance
requirement, independent of scheduling, prompt length and measured latency.

The break-even estimate divides the purchase price by the positive monthly
result, which already includes depreciation. The cumulative view also
charges purchases at the relevant timeline points. These displayed model
conventions need distinct cash-flow assumptions for a deployment forecast.
